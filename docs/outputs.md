# Hockey Stats Automation — Outputs

## Overview

This project produces both Excel and HTML outputs.

The outputs fall into three categories:

1. base season Excel workbooks
2. WPA / wins-added analysis workbooks
3. published HTML report files

---

## 1. Base season Excel outputs

The first stage of the pipeline creates season-level results workbooks.

These are generated by one of the main season scripts:

- `vhl_stats_regular_season.py`
- `vhl_stats_playoffs.py`
- `vhlm_stats_regular_season.py`
- `vhlm_stats_playoffs.py`

Typical output examples:

- `Results_VHL_100_Regular.xlsx`
- `Results_VHL_100_Playoffs.xlsx`
- `Results_VHL_101_Regular.xlsx`
- `Results_VHLM_100_Regular.xlsx`
- `Results_VHLM_100_Playoffs.xlsx`

These workbooks represent the base stat outputs used by the rest of the process.

---

## 2. Win probability coefficient output

Generated by:

- `win_probability_added.py`

Primary output:

- `Wins_Coefficient.xlsx`

Purpose:

- stores the coefficient data used for later wins-added style analysis
- acts as the intermediate metric workbook used by `analyze_wins.py`

---

## 3. WPA-enhanced results outputs

Generated by:

- `analyze_wins.py`

This step takes the base season workbook and the coefficient workbook, then writes an enhanced version of the results file with wins-added / WPA-style data included.

Typical output pattern:

- base workbook is read from `Results/`
- enhanced workbook is written to `Results/wpa/`

Example downstream outputs:

- `Results/wpa/Results_VHL_100_Regular.xlsx`
- `Results/wpa/Results_VHL_100_Playoffs.xlsx`
- `Results/wpa/Results_VHLM_100_Regular.xlsx`

Purpose:

- preserves the main season results workbook structure
- adds the wins-added / WPA-related output needed for publishing

---

## 4. Team HTML report outputs

Generated by:

- `html_reports.py`

The project creates one HTML page per team.

Folder flow shown in the working project structure includes:

- `html/S100/VHL/Regular/`
- `html/S100/VHL/Playoffs/`
- `html/S100/VHLM/Regular/`
- `html/S100/VHLM/Playoffs/`

Example team HTML outputs:

- `Calgary_Wranglers.html`
- `Chicago_Phoenix.html`
- `D.C._Dragons.html`
- `Toronto_Legion.html`

Purpose:

- display all players for a team in a publishable HTML format
- show team-level skater and goalie reporting using the enhanced dataset

---

## 5. Comparison HTML outputs

Also generated by:

- `html_reports.py`

Comparison folders shown in the working structure include:

- `html/comparisons/S100/VHL/Regular/`
- `html/comparisons/S100/VHL/Playoffs/`
- `html/comparisons/S100/VHLM/Regular/`
- `html/comparisons/S100/VHLM/Playoffs/`

Typical comparison output files:

- `defenders.html`
- `forwards.html`
- `goalies.html`

Purpose:

- compare players by position
- group players within the same league and context
- present normalized wins-added / WPA-style comparison views

---

## Output summary by type

### Excel
- base season result workbooks
- `Wins_Coefficient.xlsx`
- WPA-enhanced result workbooks in `Results/wpa/`

### HTML
- one page per team
- one page per position comparison group:
  - defenders
  - forwards
  - goalies
